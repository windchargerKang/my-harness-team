# neutral-default

## 适用场景
通用页面、原型页面、暂时无法准确归类的页面。

## 页面目标
提供保守、稳定、不出错的默认体验。

## 布局结构
- 标题区
- 主内容区
- 操作区
- 辅助说明区

## 信息密度
- 中等
- 不偏 B 端，也不偏 C 端

## 视觉风格
- 稳定
- 中性
- 低风险

## 组件优先级
1. 页面标题
2. 主内容
3. 主操作
4. 辅助说明

## 交互模式
- 默认行为清楚
- 操作反馈明确
- 不引入复杂动效

## 状态要求
- loading
- empty
- error
- success
- permission denied

## 响应式规则
- 桌面和移动端都能正常使用
- 优先确保内容完整可见

## 可访问性要求
- 文本可读
- 控件可达
- 状态反馈明确

## 允许偏离项
- 可按项目品牌轻微调整视觉表达

## 不建议做法
- 复杂化
- 风格过强
- 过度装饰
