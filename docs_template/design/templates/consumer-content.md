# consumer-content

## 适用场景
文章详情、知识库、帮助中心、文档阅读页。

## 页面目标
让用户快速阅读、定位和理解内容。

## 布局结构
- 顶部：标题 + 元信息
- 中部：正文 + 目录 / 辅助信息
- 底部：相关推荐 / 下一步

## 信息密度
- 中等
- 以阅读舒适度为主

## 视觉风格
- 干净
- 克制
- 以排版为核心

## 组件优先级
1. 正文排版
2. 目录导航
3. 引用 / 提示块
4. 相关推荐
5. 操作入口

## 交互模式
- 目录可快速跳转
- 长内容支持锚点
- 复制、分享、收藏等辅助动作不抢主线

## 状态要求
- loading：内容骨架
- empty：说明暂无内容
- error：给出重试和返回路径
- success：内容加载成功后无干扰
- permission denied：说明访问限制

## 响应式规则
- 小屏下目录折叠
- 正文字号、行高要适合移动端阅读

## 可访问性要求
- 标题层级清晰
- 长文排版可读
- 链接和按钮可聚焦

## 允许偏离项
- 可按内容类型调整正文宽度
- 可根据品牌轻微调整辅助区样式

## 不建议做法
- 正文挤得太密
- 目录抢视觉
- 过度使用卡片切块
