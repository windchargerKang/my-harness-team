# b2b-dashboard

## 适用场景
管理后台首页、数据看板、列表聚合页、运营总览。

## 页面目标
让用户快速看懂当前状态，并高效完成筛选、查看和操作。

## 布局结构
- 顶部：页面标题 + 简短说明 + 关键操作
- 中部：统计卡片 / 筛选区 / 主数据区
- 底部：详情、辅助信息或日志区

## 信息密度
- 高
- 优先展示核心指标和操作入口
- 避免大面积留白

## 视觉风格
- 克制
- 稳定
- 清晰
- 不追求强烈装饰感

## 组件优先级
1. 表格
2. 筛选器
3. 统计卡片
4. 抽屉 / 弹窗详情
5. 批量操作

## 交互模式
- 默认支持筛选、排序、分页
- 关键操作要有确认或反馈
- 批量操作要清晰提示影响范围

## 状态要求
- loading：骨架屏或轻量 loading
- empty：明确解释“为什么空”
- error：能恢复、能重试
- success：有清晰结果反馈
- permission denied：说明权限不足和下一步

## 响应式规则
- 小屏优先保留核心筛选与主数据区
- 次要辅助区可折叠或移入抽屉

## 可访问性要求
- 表格和筛选控件可键盘操作
- 状态提示可读
- 主次按钮有明确区分

## 允许偏离项
- 可根据品牌色调整强调色
- 可根据页面复杂度调整组件密度

## 不建议做法
- 大面积留白
- 过度动画
- 把关键操作藏得太深
