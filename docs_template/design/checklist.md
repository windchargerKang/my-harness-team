# Frontend Design Checklist

## 适用阶段
- apply
- verify
- review

## 基础检查
- [ ] 是否识别了 UI 变更
- [ ] 是否选择了合适模板
- [ ] 是否说明了模板选择理由
- [ ] 是否列出了允许偏离项
- [ ] 是否记录了实际偏离

## 页面结构检查
- [ ] 是否有明确主标题
- [ ] 是否有清晰的主操作区
- [ ] 是否有辅助操作区
- [ ] 是否有必要的信息分组
- [ ] 是否避免了无意义的视觉装饰

## 状态检查
- [ ] loading
- [ ] empty
- [ ] error
- [ ] success
- [ ] permission denied

## 交互检查
- [ ] 表单提示是否贴近输入项
- [ ] 主次按钮是否区分清楚
- [ ] 关键动作是否有反馈
- [ ] 失败状态是否可恢复

## 可访问性检查
- [ ] 键盘可用
- [ ] 对比度足够
- [ ] 文本可读
- [ ] 交互状态有视觉反馈

## 偏离记录
- [ ] 偏离原因是否明确
- [ ] 偏离是否影响体验
- [ ] 是否需要后续优化
