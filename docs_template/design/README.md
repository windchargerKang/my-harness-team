# 前端设计资源

本目录用于预置前端设计规范与 UI 模板资源，安装时会复制到目标项目的 `openspec-team/design/`。

## 文件说明

- `principles.md`：全局前端设计原则
- `checklist.md`：`apply` / `verify` / `review` 共用检查清单
- `mapping.md`：按页面类型选择模板的规则
- `templates/`：适用于常见场景的标准化 UI 模板

## 模板列表

- `b2b-dashboard.md`
- `b2b-form-heavy.md`
- `consumer-marketing.md`
- `consumer-content.md`
- `neutral-default.md`
