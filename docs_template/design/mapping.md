# Template Mapping

## 映射原则

优先根据页面目标和信息结构选择模板，而不是按技术栈选择。

## 模板映射

### b2b-dashboard
适用：
- 管理后台首页
- 数据看板
- 列表聚合页
- 监控页
- 运营后台概览

### b2b-form-heavy
适用：
- 新增页
- 编辑页
- 审批页
- 配置页
- 多步骤表单页

### consumer-marketing
适用：
- 营销页
- 活动页
- 注册转化页
- 品牌展示页
- landing page

### consumer-content
适用：
- 文章详情
- 知识库
- 帮助中心
- 文档页
- 长文本阅读页

### neutral-default
适用：
- 无明显行业特征
- 暂时无法判断场景
- 原型阶段
- 低风险通用页面
